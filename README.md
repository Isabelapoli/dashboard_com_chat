# dashboard_com_chat
https://isabelapoli.github.io/dashboard_com_chat/
Dashboard feito no ChatGPT com Canvas para responder as seguintes perguntas de negócio:

->Qual foi o ano mais fraco e melhor de vendas?
->Qual modelo mais vendido de acordo com o ano?
->Qual estado tem mais compradores?

Mas antes de enviar para o ChatGPT, os dados da planilha foram tratados para todos terem a mesma formatação, textos e números quebrados corridos e o que era fórmula ser colado como Valores para não perder nenhuma informação. 

O prompt inicial no chat foi: 
utilizando o recurso canvas, renderize uma dashboard em html ao lado 

#Filtros
->Modelo da Porsche
->Model Year
->City
->Pay Method

#Perguntas de negócio
->Qual foi o ano mais fraco e melhor de vendas
->Qual modelo mais vendido de acordo com o ano
->Qual estado tem mais compradores

Sobre o design ui/ux 
->design clean com os números em destaque

O primeiro processamento dos dados entregou uma dashboard bem completa, mas um dos gráficos não deixava claro qual informação estava sendo passada. Então, o modelo foi trocado usando comando de linguagem natural.
